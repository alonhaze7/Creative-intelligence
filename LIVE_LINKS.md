## 📹 **About the Video**

You mentioned adding a video (`My Movie rotem 01.mp4` - 223MB). 

**Note**: This video is **NOT** in the GitHub repo because:
- GitHub has a 100MB file size limit
- Large videos slow down git operations

### Options for Including Your Video:

#### Option 1: YouTube (Recommended)
1. Upload video to YouTube
2. Embed in the dashboard using an iframe:
```html
<iframe width="560" height="315" 
  src="https://www.youtube.com/embed/YOUR_VIDEO_ID" 
  frameborder="0" allowfullscreen>
</iframe>
```

#### Option 2: Vimeo
1. Upload to Vimeo
2. Use Vimeo embed code

#### Option 3: Git LFS (Large File Storage)
```bash
# Install Git LFS
brew install git-lfs
git lfs install

# Track video files
git lfs track "*.mp4"
git add .gitattributes
git add "My Movie rotem 01.mp4"
git commit -m "Add video via Git LFS"
git push
```
