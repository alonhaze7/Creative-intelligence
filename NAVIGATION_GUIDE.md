## 🎨 Visual Design System

### Color Palette
- **Primary**: `#6366f1` (Indigo) - Main brand color, CTAs
- **Secondary**: `#8b5cf6` (Purple) - Accents, gradients
- **Success**: `#10b981` (Green) - Positive metrics, success states
- **Warning**: `#f59e0b` (Amber) - Attention, moderate priority
- **Danger**: `#ef4444` (Red) - Alerts, high priority
- **Dark**: `#1e293b` (Slate) - Headers, primary text
- **Light**: `#f8fafc` (Gray) - Backgrounds, subtle elements

### Typography
- **Font Family**: System fonts (-apple-system, Segoe UI, Roboto)
- **Headers**: Bold, gradient text effects
- **Body**: Regular weight, 1.6 line-height for readability
- **Labels**: Smaller, secondary color for hierarchy

### Components
- **Cards**: White background, rounded corners, shadow on hover
- **Charts**: Chart.js with matching color palette
- **Badges**: Rounded pills for status indicators
- **Buttons**: Gradient backgrounds with hover effects
- **Insights**: Left-bordered cards with tags
